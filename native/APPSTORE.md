# Пайплайн: soul → App Store

Честный план как довести приложение до App Store. Без сахара: это не «нажать кнопку», а проект на ~1-2 недели + $99/год.

---

## 0. Реальность и блокеры

**Стоимость:** Apple Developer Program — **$99/год** (обязательно, иначе в Store никак). ⛔ это единственный платный шаг; обойти нельзя.

**Три блокера ревью именно под наше приложение** (Apple завернёт, если не решить ДО сабмита):

| # | Guideline | Проблема | Что делать |
|---|-----------|----------|------------|
| **Б1** | **4.2 Minimum Functionality** | чистый WKWebView, грузящий сайт, Apple считает «просто сайт в обёртке» и реджектит | усилить нативную ценность: пуши, нативные настройки/Face ID-замок (у нас есть), офлайн-режим, шаринг. Подать как полноценное приложение, не «вьюер сайта» |
| **Б2** | **4.8 Sign in with Apple** | даём вход через Google → Apple ТРЕБУЕТ также «Войти с Apple» | добавить Sign in with Apple на экран входа (бэкенд + натив) ИЛИ убрать сторонние логины |
| **Б3** | **5.1.1(v) Account Deletion** | есть аккаунт (Google) → обязана быть кнопка удаления аккаунта В приложении | добавить «удалить аккаунт и данные» в профиль (бэкенд-эндпоинт + UI) |

Плюс, т.к. это **ментальное здоровье**:
- дисклеймер «не заменяет врача/не экстренная помощь» + кризисные контакты (у нас уже есть в промпте — вынести в видимый UI).
- privacy policy URL (обязателен) + честные Privacy Nutrition Labels (собираем чувствительные данные).

> **Вывод:** прежде чем платить $99 — сделать Б1-Б3 и privacy. Иначе деньги уйдут, а ревью завернёт.

## 1. Что доработать в приложении (до сабмита)

- [ ] **Sign in with Apple** (Б2): capability + бэкенд `/api/auth/apple` (как google, через Apple OAuth/JWT) + кнопка на authScreen.
- [ ] **Удаление аккаунта** (Б3): `/api/account/delete` (стирает user, сессии, дневник, сообщения, профиль) + кнопка в профиле с подтверждением.
- [ ] **Нативная ценность** (Б1): хотя бы пуш-уведомления (напоминания вести дневник) ИЛИ заметный нативный слой. Face ID-замок у нас уже нативный — подчеркнуть.
- [ ] **Дисклеймер + кризис-блок** видимым экраном (не только в ответах ИИ).
- [ ] **Privacy policy** страница (можно на нашем домене `/privacy`) + ссылка в приложении.
- [ ] Иконка 1024 без альфа-канала (уже есть), скриншоты 6.7" и 6.5".

---

## 2. Apple Developer + App Store Connect

1. **Регистрация:** developer.apple.com → Enroll → $99/год (физлицо или ИП/ООО). Подтверждение 24-48 ч.
2. **Team ID:** Membership → запомни `Team ID` (10 символов). Вставь в `archive.sh` (`APPLE_TEAM_ID`) и `ExportOptions.plist`.
3. **App ID / Bundle:** наш `app.soul.client`. В Xcode → Signing & Capabilities → Team = твой → Automatic signing создаст профиль сам. Добавь capability **Sign in with Apple** (для Б2), **Push Notifications** (если делаешь пуши).
4. **App Store Connect** (appstoreconnect.apple.com) → My Apps → **+** → New App:
   - Platform: iOS, Name: `soul`, Primary Language, Bundle ID: `app.soul.client`, SKU: любой (`soul-001`).

---

## 3. Метаданные и приватность (в App Store Connect)

- **App Information:** категория Health & Fitness (или Medical — но Medical = строже ревью), age rating (выставить честно: ментальные темы → 17+ скорее всего).
- **Privacy Policy URL** — обязателен.
- **App Privacy (Nutrition Labels):** задекларировать сбор: Email (Account), User Content (дневник, сообщения — Sensitive Info / Health). Связано с пользователем. Не для трекинга.
- **Демо-аккаунт для ревью** (КРИТИЧНО): у нас вход через Google → ревьюер не зайдёт. В App Review Information → дать тестовый логин/пароль ИЛИ включить временный обходной вход. Без этого — авто-реджект.
- Скриншоты (6.7": 1290×2796, 6.5": 1242×2688), описание, ключевые слова, support URL.

## 4. Сборка и загрузка

После того как Б1-Б3 готовы и Team ID вписан:

```bash
cd native
APPLE_TEAM_ID=XXXXXXXXXX ./archive.sh      # archive + export IPA → build/ipa/soul.ipa
```

Загрузка билда в App Store Connect — любой из:
- **Xcode Organizer** (проще): Window → Organizer → выбрать архив → Distribute App → App Store Connect → Upload.
- **CLI** (App Store Connect API key из ASC → Users and Access → Integrations → Team Keys):
  ```bash
  xcrun altool --upload-app -f build/ipa/soul.ipa -t ios \
    --apiKey $ASC_KEY_ID --apiIssuer $ASC_ISSUER_ID
  ```

## 5. TestFlight → Review → Release

1. **TestFlight:** билд появится в ASC через ~10-30 мин (processing). Internal Testing — сразу себе на iPhone (приложение TestFlight). External — лёгкий ревью (~1 день). **Тут проверяешь на реальном устройстве до публикации.**
2. **Submit for Review:** заполнить всё → Add for Review → Submit. Ревью обычно **1-3 дня**.
3. **Release:** после Approved — Manual или Automatic release.

## 6. Частые реджекты (предупредить заранее)

- **4.2** «webview-обёртка» → усилить натив (Б1), в Review Notes описать нативные функции (Face ID-замок, хаптика, голос, пуши).
- **4.8** нет Apple Sign In при наличии Google → Б2.
- **5.1.1** нет удаления аккаунта → Б3.
- **2.1** ревьюер не смог войти → демо-аккаунт в Review Information.
- **5.1.1 (privacy)** нет/слабая privacy policy для чувствительных данных → нормальный документ.
- **1.4.1 / медицина** обещания «лечения» → формулировки «поддержка, не замена терапии» + кризис-ресурсы.
