# soul — нативное приложение (iOS + macOS)

Нативная обёртка нашего веб-аппа: один SwiftUI-проект на **iPhone и Mac**. Внутри — `WKWebView`, грузит прод `https://moodmind-32at.onrender.com`. Логика, дизайн, бэкенд — те же, без дублирования.

## Что нативного (адаптация/оптимизация)
- **Тактилка по-настоящему.** JS-мост `webkit.messageHandlers` → CoreHaptics. Чинит вибро в standalone iOS, где у PWA её не было.
- **Без резинового оверскролла**, без зума, прозрачный фон под `--page-bg` — нет белых вспышек.
- **JS `confirm/alert/prompt`** показываются нативными диалогами (в голом WKWebView их нет — иначе тест/лок молча ломались).
- **Внешние ссылки** (`tel:`, `mailto:`, новые окна на чужой домен) → системный браузер.
- **Google-вход** работает: выставлен реалистичный Safari-User-Agent (иначе Google режет embedded webview как `disallowed_useragent`).
- **Микрофон** (голосовые заметки) — `NSMicrophoneUsageDescription` прописан.
- Иконка `soul` из общих PNG, размеры под iOS и macOS.

## Сборка (бесплатно, без App Store)

Нужен **полный Xcode** (бесплатно из App Store) + xcodegen (`brew install xcodegen`).

```bash
cd native
./build.sh          # генерит soul.xcodeproj и открывает в Xcode
```

В Xcode:
1. Таргет **soul** → схема: **My Mac** (для Mac) или **свой iPhone** по кабелю.
2. **Signing & Capabilities** → **Team** = твой Apple ID (хватит бесплатного).
3. **⌘R** — запуск.

### Поставить на iPhone бесплатно
Бесплатный Apple ID подписывает приложение на **7 дней** (потом пересобрать ⌘R). iPhone: *Настройки → Основные → VPN и управление устройством* → доверь своему сертификату. На Mac запуск без ограничений по времени.

> Платный Apple Developer ($99/год) нужен только для публикации в App Store или подписи без срока — для личного использования не требуется.

## Поменять адрес сервера
`Sources/soulApp.swift` → `appURL`.

## Почему обёртка, а не полный реврайт
У нас уже отполированный веб-UI и весь бэкенд. Нативный реврайт UI = месяцы и второй источник правды без выгоды. Обёртка даёт нативную иконку/окно/тактилку/диалоги и общий код. Один деплой webapp → обновляются и сайт, и приложение.

## Структура
```
native/
├── project.yml          # конфиг XcodeGen (iOS+macOS, один таргет)
├── build.sh             # генерация + открытие
├── Sources/
│   ├── soulApp.swift     # @main, окно, прод-URL
│   └── WebContainer.swift# WKWebView + хаптик-мост + диалоги + внешние ссылки
└── Resources/Assets.xcassets/AppIcon.appiconset   # иконки
```
`soul.xcodeproj` генерится из `project.yml` (в гит не кладётся).
